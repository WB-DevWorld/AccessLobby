# ADR 004 — Pilot peers

SOURCE-CONFIRMED: POII and DonLoft consume identity while owning their domain rights. MVP-PROVISIONAL: pilot cohort, feature-flagged auth adapter and explicit `(issuer, sub, person)` to local user mapping. Do not turn email matches into links. Preserve any current auth only as a documented transitional route; inspect the real peer repository before editing. Revisit when identity migration and account-linking policy is approved.
